# Upscale observer

Перенос проекта из чата «Прогревы поиск и паттерны» за 21 октября 2026 года,
начиная с 12:27 по Москве. Исходный архив импортирован без изменения его файлов.

- [Итоговый контекст и последние правила стратегии](context/2026-10-21/CONTEXT.md).
- [Переписка: 33 диалога, 121 сообщение](context/2026-10-21/conversation.md).
- [Машиночитаемый экспорт](context/2026-10-21/conversation.json).
- [Опись архива и скриншотов](context/2026-10-21/import-manifest.json).
- [Подготовка и запуск облачной среды](CLOUD_ENVIRONMENT.md).
- [Исходная инструкция](README_RU.txt).

Приложение наблюдает за пятью FX-парами и поддерживает Telegram-уведомления.
Автоматическое исполнение сделок в исходном коде не реализовано.

Проверка разработки:

```bash
bash scripts/cloud_setup.sh
/workspace/.venvs/upscale_bot/bin/python scripts/cloud_run.py status
```

Сеть и привязка Telegram описаны в `CLOUD_ENVIRONMENT.md`.
Историческая переписка содержит прежние инструкции и промежуточные выводы;
актуальные правила собраны в `CONTEXT.md`.
