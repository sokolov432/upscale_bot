Подключение к Solana

Если свой RPC сохранён, сначала используется он; иначе — PublicNode, затем Solana public RPC. При HTTP 403 реестра Pump.fun создатель читается из аккаунта программы, а создания — из транзакций через RPC. При недоступности RPC источник переключается; при ограничении 429 программа ждёт и не перебирает узлы ради обхода лимита.

Ссылка хранится только в расширении. Путь и ключ RPC не передаются сайту и не включаются в отчёт. Разрешение запрашивается только для выбранного вами сервера.

После сохранения обновите страницу DevLens и запустите поиск заново.
