DevLens 1.5 — этот чат автоматически, память наблюдений

1. Распакуйте ZIP в постоянную папку.
2. Chrome/Edge: chrome://extensions → Режим разработчика →
   Загрузить распакованное расширение → выберите папку с manifest.json.
   Для обновления замените файлы в прежней папке и нажмите «Обновить».
3. Оставьте этот разговор ChatGPT со ссылкой на обновление открытым
   в том же браузере. Расширение узнаёт его по метке ссылки.
   Кнопка выбора/привязки чата больше не нужна.
4. На Axiom нажмите лупу возле названия токена. Ответ вернётся в карточку.

API-ключ не нужен. Браузер и этот чат должны оставаться открытыми.
Сохраняются карточки токенов, факты из ответов, доступные изображения
графиков и профили X, открытые в браузере для уже известных токенов.
Недоступные поля остаются неизвестными. Сходство не доказывает владельца.
База хранится локально в IndexedDB; резервная копия — в окне расширения.
Недавний ответ повторно показывается из кэша до 3 минут с датой проверки.
Для нового исследования есть «Проверить заново» / «Обновить без кэша».
Личные записи и изображения не загружаются на публичный сайт.
В чат передаются только ограниченные факты сравнения, без изображений,
ключей, баланса и позиций. Расширение не открывает сделки.
Если график защищён/недоступен, снимок не делается. Внешние сайты могут
изменить разметку; тогда потребуется обновление расширения.
