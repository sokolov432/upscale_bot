АРХИВ UPSCALE — 21.10.2026

СОСТАВ И СОСТОЯНИЕ
Код наблюдателя, актуальная стратегия, тесты, результаты первичной проверки,
справочные снимки состояния и проверка исправленного сигнала.
Реализованы наблюдение и Telegram-уведомления. Автоматическое открытие/закрытие
сделок НЕ реализовано. Включение execution_enabled будет отклонено кодом.
Архив не содержит токенов, cookies и авторизованной сессии Upscale/TinyFish.

ТЕКУЩАЯ СТРАТЕГИЯ
Пары: AUD/USD, EUR/USD, GBP/USD, USD/JPY, USD/CHF.
Таймфрейм: 5 минут. Heikin Ashi рассчитываются из обычных OHLC Upscale.
Учитываются только закрытые свечи.
Лонг: минимум две красные, затем три зелёные; закрытие второй зелёной выше
полного максимума первой (C2>H1), третьей — выше максимума второй (C3>H2).
Шорт: минимум две зелёные, затем три красные; C2<L1 и C3<L2.
Выход: после закрытия первой свечи противоположного цвета.
Фильтр объёма отключён пользователем.
Настройки будущей демосделки: маржа $6000, плечо x30, стоп 0,05% от фактической
цены исполнения. Это настройки стратегии, а не работающий исполнитель ордеров.
Проверки: каждые пять минут +2 секунды. Новые сигналы блокируются при задержке
проверки более 5 секунд. Доставка Telegram имеет отдельную сетевую задержку.

ЗАПУСК НА НОВОЙ МАШИНЕ
Код рассчитан на Linux: использует fcntl, Unix-сигналы и /usr/bin/chromium.
Нужны Python 3.11+ и Chromium. Пример для Debian/Ubuntu:

sudo apt-get update
sudo apt-get install -y python3-venv chromium
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python configure_telegram.py
python -m unittest -v
python supervisor.py

configure_telegram.py запросит токен скрытым вводом, проверит бота через getMe
и выведет персональную ссылку для привязки. Открой ссылку и нажми Start.
Файл telegram.example.json — только образец структуры, без реального токена.
На машине должен быть доступ к app.upscale.trade и api.telegram.org.
Сохраняй необходимые настройки HTTPS_PROXY/HTTP_PROXY и доверенных сертификатов.
При переносе останови старый экземпляр: один бот не должен одновременно
опрашиваться несколькими процессами на разных машинах.

ПРОВЕРКА И УПРАВЛЕНИЕ
python monitor.py status — состояние последней проверки.
python monitor.py once — разовая проверка без отправки входных сигналов.
Команды Telegram: /status, /pause, /resume, /stop.
/pause приостанавливает рыночные проверки, включая уведомления о выходе.
/stop завершает работу; supervisor не перезапускает намеренную остановку.
При аварии worker перезапускается supervisor с задержкой 5–60 секунд.
Для работы после выхода из терминала нужен свой менеджер процессов/сервис.
Постоянный хостинг этим архивом не настроен.

ПРИВАТНОЕ СОСТОЯНИЕ
На новой машине создаётся ~/.local/state/upscale-demo/.
Там находятся токен, привязка чата, курсор Telegram, журнал и состояние процесса.
В архив они не включены. Права каталога 0700, файлов 0600.
Справочные JSON в reference/ не являются готовой копией для восстановления
процесса и не должны заменять приватное состояние. На старте исторические
сигналы не рассылаются; отслеживание прежних уведомлений на новой машине
нужно учитывать отдельно. Уже открытые вручную позиции бот не проверяет.

ОГРАНИЧЕНИЯ
Наблюдатель не имеет доступа к торговому аккаунту; TinyFish ему не требуется.
preflight.json фиксирует прежние наблюдения, а не текущий баланс/настройки.
Справочный снимок показывает состояние только на момент упаковки.
Исчезновение/приостановка облачной среды остановит работающий в ней процесс.
Токен заново вводится локально; пересылать его в переписке не требуется.
