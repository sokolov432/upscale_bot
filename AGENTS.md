# Solana investigation memory

For a new Solana CA investigation, first read `devlens/RESEARCH_WORKFLOW.md` and
look up the CA in `devlens/research/token-memory.json` with
`node devlens/memory-cli.mjs lookup CA`. This is the user's private working
catalogue, ignored by git. A missing catalogue is an empty memory, not an error.

Record each investigated token and newly observed facts using
`node devlens/memory-cli.mjs remember PRIVATE_CASE.json`. Keep observation times
and public evidence sources. Compare funding, source-chain makers, X profiles
and comparable chart snapshots before repeating network work. Do not invent
missing charts, followers or facts. Attached/quote assets, pooled exchange
wallets and generic bridge solvers are not previous developer launches.

Never publish personal catalogue records, private RPC URLs or keys in `docs/`,
extension ZIPs, logs or AI prompts. The user's explicit instructions take
precedence over this workflow. No background work is implied after a turn ends.
